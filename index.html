Bem-vindo

Protótipo simplificado de orçamentação para marcenaria em MDF, desenvolvido para a oficina de Deborah e Rafael Sanches (Tapiratiba – SP).

Hoje eles usam uma planilha que leva de 2 a 3 dias para montar um orçamento e ainda gera erro de material e mão de obra. Este sistema é a primeira versão para testar uma solução mais rápida.

    Sobre o projeto

    Disciplina: Projeto Integrador em Computação II (PJI240)

    Comunidade: Oficina de Deborah e Rafael Sanches — Tapiratiba, SP

    Problema: orçamentação manual em planilha, lenta e com erros de material e mão de obra.

    Solução: protótipo web em JavaScript para calcular orçamentos de MDF.

    Metodologia: Design Thinking (empatia → definição → ideação → protótipo → teste).

    Tecnologias (protótipo atual)

    HTML5CSS3JavaScript localStorage

    Na versão final do PI: framework web, banco de dados, API, nuvem, testes e controle de versão (conforme tema norteador da UNIVESP).
